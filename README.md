# Kampklar - youth handball platform preview

Interactive preview of a secure registration platform for young handball players:
parent sign-up with email codes, several children per account, consent forms with
signed PDF copies, GDPR tools (export, withdraw, delete) and a two-step admin dashboard.

Runs entirely in the browser. Demo data is stored locally, and every email lands in the
built-in Demo inbox. Admin demo login is shown on the admin screen.
